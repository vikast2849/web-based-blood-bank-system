# Project Documents

This directory contains the academic project documentation, presentation materials, and system screenshots for the **Web-Based Blood Bank System**.

## Directory Structure

| Folder | Contents |
|---|---|
| [`report/`](./report/) | Official Mini-Project Report (`Blood_Bank_Report.pdf`) approved by Dept. of CS&E, SJMIT. |
| [`synopsis/`](./synopsis/) | Project synopsis summary (`project_synopsis.md`) detailing problem statement, objectives, and architecture. |
| [`ppt/`](./ppt/) | Presentation structure and seminar slide outline (`presentation_notes.md`). |
| [`screenshots/`](./screenshots/) | High-resolution UI captures of the live application (`home.png`, `login.png`, `register.png`, `available_samples.png`). |
